# v0.3.13：手机端支持

开发前 Git 存档：`codex/checkpoint-before-mobile-support-03b1bba`。本次只调整显示、触控命中和移动端资源档位，不修改寻路、战斗、兵线持续、AI 或结算规则。

## 可用空间与全屏

特色服务器的对局页使用 `viewport-fit=cover`、`100dvh`、Visual Viewport 高度以及四边 `safe-area-inset-*`，避免浏览器地址栏、刘海和系统手势区盖住控件。手机竖屏首次进入时提供“全屏并横屏”和“暂时继续”；前者必须由玩家点击，因为移动浏览器禁止网页在没有用户手势时直接进入全屏。进入全屏后会在浏览器允许时锁定横屏。iOS 等不开放网页全屏的环境提示通过“添加到主屏幕”获得沉浸显示。

战场主菜单移至底部 44px 触控栏，宽度不足时可横向滚动。玩家身份留在顶部两侧，时间位于其下；聊天、性能、全屏、途中遭遇提示和命令提示避开底栏。所有面板使用动态视口高度和内部滚动，决策、研发、事件、工具、暂停和据点操作不会伸出可见区域。

## 触控操作

- 据点屏幕命中半径扩大到原来的 1.65 倍且至少为 28px；己方单位命中半径从 32px 增至 46px，兵线命中距离从 11px 增至 22px。
- 据点详情固定为底部面板，姿态按钮和改名按钮为 46px；地图缩放按钮在面板打开时自动隐藏。
- 己方据点增加“选择调兵目标”。点击后关闭面板，再点任意目标据点即可使用原 `configureRouteChain` 建立同一条权威持续兵线；再次点原据点取消。服务器仍只接收原有据点命令。
- 左侧提供放大、缩小和回到战场中心按钮。触控缩放速度由 0.72 提升到 1.08，最近距离由 13 放宽到 9，最远距离由 58 放宽到 82。
- 竖屏相机视场从 38° 调整为 58°并采用更远的初始位置；旋转屏幕后重算投影，返回中心和阵营视角也使用对应距离。

## 移动性能档

自动画质在手机从 low 开始，且最多提升到 medium。自动档的渲染比例为 0.62～0.78；以原中档 DPR 1.0 比较，低档像素数量减少约 62%。阴影、动态灯光、窗户和屋顶细节关闭，WebGL 抗锯齿在创建上下文时关闭；详细单位为 36～72 个，交火粒子最多 5 个。玩家手动选择低、中、高画质时仍使用对应的明确设置。

`scripts/mobile-support-regressions.ts` 检查竖屏/横屏手机识别、自动画质起点与上限、手动画质、命中半径、安全区、全屏入口、缩放和点选调兵。浏览器验收覆盖 390×844 大厅、模式与阵营选择、竖屏相机、据点底部面板、点选目标兵线、决策页面，以及 844×390 横屏对局壳。
